# Minseo Kwak — Research Portfolio

A static, multi-page research portfolio prepared for GitHub Pages.

## Pages

- Home
- About
- Research
- Publications
- Conference
- Beyond the Lab

The site uses plain HTML, CSS, and JavaScript, so no build command is required.

## Offline preview

Download and extract the repository, then double-click the root `index.html`
file. Navigation links are adjusted automatically when the site is opened from
a local file, so every page works without installing software or running a
server.

## Local preview

Run a static server in this directory, for example:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## GitHub Pages

In the repository settings, open **Pages**, choose **Deploy from a branch**, and select the root of the `main` branch.
